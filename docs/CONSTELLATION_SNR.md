# 等化出力の星座解析 — 1seg 復調不能の原因確定

2026-09-30。`captures/atk3.iq` の RS ブロック 400 を原子ダンプし、
等化出力の soft 値（f32）を解析した結果。

## 結論（先に）

**コードにバグはない。受信 SNR が約 4.5 dB しかなく、1seg 復調に必要な
値（约 20 dB）より 15 dB 以上不足している。**

等化器・Viterbi・RS・byte 整列・PRBS はすべて正しく動作している。
0.4% しか完全復調できない観測結果は、入力が劣すぎることで完全に説明される。

## 母数（重要）

`ISDBT_ATOM=400` で原子スナップショット（ブロック完了の瞬間に一括採取）。

- soft 30000 トレリスステップ
- うち punctured を除く完全な (X, Y) 対 = **15000**
- erasure 率 25.0%（レート 2/3 の [1,1,0,1] と厳密一致）

以下はすべて **15000 対**での実測。分母を明記しない数値は信用しない。

## 1. 4QAM 構造は健全

星座の四隅の分布:

| 角度 | 割合 | 理想 |
|---|---|---|
| 45° (+,+) | 24.90% | 25% |
| 135° (-,+) | 25.34% | 25% |
| 225° (-,-) | 24.91% | 25% |
| 315° (+,-) | 24.85% | 25% |

- X 軸: mean -0.0024, stdev 0.8307
- Y 軸: mean +0.0038, stdev 0.8210

→ 偏りなし、位相回転なし、DC バイアスなし。
変調器・キャリア同期・周波数同期・等化器は正常。

## 2. 残留は白色ノイズ（ISI ではない）

|X − A| の自己相関:

| lag | r |
|---|---|
| 1 | -0.0127 |
| 2 | -0.0001 |
| 3 | +0.0047 |
| 4 | +0.0110 |
| 5 | +0.0181 |
| 8 | +0.0049 |
| 12 | +0.0065 |
| 16 | -0.0047 |

全て |r| < 0.02。**多径・ISI による残差ではなく純粋な白色雑音。**
等化器を改造しても改善しない。

## 3. SNR

|QPSK| 分布を理論（信号 ±A + ガウス σ）に fit:

- A = 0.720
- σ = 0.430
- **SNR = A/σ = 1.674 = 4.48 dB**
- 推定 pe = Q(A/σ) = **0.047**（10万ビット中 4700 誤り）

K=7 自由距離 10（3 ビット訂正可能）に対し pe=4.7% は訂正限界を大きく超える。
訂正後に残る誤り > RS(204,188,t=8) の能力 8 シンボル。

→ 0.4% しか完全復調できない結果と**完全に整合**。

## 対策（コードではなく電波）

1. **夜間に受信する** — 都市雑音が減る
2. **アンテナを確認する** — 1seg は水平偏波。DS-DT-305BK の卓上アンテナは
   470–620 MHz での利得不十分な可能性
3. **受信距離を短くする / 遮蔽物を避ける**

手動ゲインは 0 固定。8bit ADC 飽和で TMCC が壊れる（既知）。

## 付録: この診断で判明した計測器のバグ

段階間比較が「A 段は正常、B 段が壊れている」という**誤結論**を
出していたのは、soft / vit / RS 入力を**別々のリングから別々に**
切り出していたため。原子スナップショットを作って初めて比較が成立した。

1. `dump_byte` の捕捉条件が常に偽（`rs_blocks_seen` の `+= 1` より前に比較）
2. soft リングの drain を vit と共有 → vit が毎回ほぼ空
3. `dump_soft_f32` が depuncture **前**（kept）を捕捉。Viterbi は**後**（mother）を見る
4. soft と vit のリング長を別々にすると同じ時間窓にならない（ステップ数で統一）
5. `ByteDeinterleaver::push` は `idx % BI_I` で分岐を選ぶ。
   offline 再生は `prime_phase()` で idx を合わせる必要あり

なお soft と vit を直接比較するのは**構造的に無意味**。
soft は畳み込み符号の**符号化後**、vit はその**復号結果**で、
対応関係がない。Viterbi 実装自体は既存テスト（rate 1/2・2/3 round-trip、
streaming 遅延一致）で正常。
